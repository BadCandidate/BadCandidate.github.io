📥 Cách Đóng Góp Thông Tin

Nếu bạn từng gặp phải một ứng viên gây thất vọng — như bỏ phỏng vấn không báo trước, khai sai thông tin, thiếu kỹ năng cơ bản, thô lỗ hoặc có hành vi độc hại — bạn có thể đóng góp thông tin cho cộng đồng.

🚀 Ba Cách Đóng Góp Chính

Tùy chọn 1: Pull Request (Khuyến nghị)

Gửi Pull Request (PR) với hồ sơ của ứng viên đến repository GitHub công khai:

👉 GitHub Repository

Admin sẽ cập nhật vào trang web và trả về link của ứng viên thông qua PR bạn đã tạo.

Tùy chọn 2: Discussion

Tạo Discussion trong phần Bad Candidates:

👉 GitHub Discussions

Admin sẽ cập nhật vào trang web và trả về link của ứng viên thông qua discussion bạn đã tạo.

Tùy chọn 3: Email (Không khuyến khích)

Gửi email đến:

👉 Contact Email

Admin sẽ cập nhật vào trang web và trả về link của ứng viên thông qua email cho bạn sau khi đã validate thông tin.

📋 Nội Dung Cần Bao Gồm

  • Mô tả rõ ràng, tôn trọng và khách quan về vấn đề
  • Bối cảnh liên quan (ví dụ: vị trí tuyển dụng, giai đoạn phỏng vấn, hành vi quan sát được)
  • Không bao gồm thông tin cá nhân nhạy cảm (vd: tên thật, số điện thoại, email, giấy tờ tùy thân)

❓ Hỏi Đáp & Thắc Mắc

Nếu bạn có câu hỏi hoặc thắc mắc về dự án này, vui lòng gửi tại:

👉 Q&A Discussions

⚠️ Nguyên Tắc Cộng Đồng

  • Ghi nhận thông tin đúng sự thật – Không chấp nhận công kích cá nhân hay báo cáo sai sự thật
  • Không phân biệt đối xử – Mọi nội dung kỳ thị về chủng tộc, giới tính, quốc tịch… đều bị nghiêm cấm
  • Giữ tính chuyên nghiệp – Đây là công cụ giúp bảo vệ doanh nghiệp, không phải nơi bêu rếu

🛡️ Bảo Vệ Quyền Riêng Tư

  • Không chia sẻ thông tin cá nhân của ứng viên
  • Chỉ báo cáo hành vi không phù hợp trong môi trường chuyên nghiệp
  • Tập trung vào sự kiện thay vì đánh giá cá nhân

🚫 Welcome to the Bad Candidate List 🚫

Official website collecting and sharing honest, professional feedback on candidates who have demonstrated poor performance, unprofessional behavior, or toxic attitudes during interviews or employment.

🎯 Main Purpose

Our mission is to help recruiters, hiring managers, and companies avoid bad hiring decisions by maintaining a community-driven record of candidates with consistent red flags.

📥 How to Contribute Information

If you've encountered a candidate who truly stands out for the wrong reasons — ghosting, lying on CVs, failing basic tasks, being rude, or showing toxic behavior — we invite you to contribute.

🚀 Three Main Contribution Methods

Option 1: Pull Request (Recommended)

Submit a Pull Request (PR) with the candidate's profile to our public GitHub repository:

👉 GitHub Repository

Admin will update the website and return the link of bad candidate via PR that you created.

Option 2: Discussion

Create a Discussion in the Bad Candidates category:

👉 GitHub Discussions

Admin will update the website and return the link of bad candidate via discussion that you created.

Option 3: Email (Not Recommended)

Send email to:

👉 Contact Email

Admin will update the website and return the link of bad candidate after reviewing all the information.

📋 Content Requirements

Your contribution should include:

  • Clear, respectful summary of the issue
  • Relevant context (e.g. job title, interview stage, behavior observed)
  • No private or sensitive information (e.g., real names, contact details, documents)

❓ Q&A & Questions

If you have questions or concerns about this project, please post them at:

👉 Q&A Discussions

⚠️ Community Guidelines

  • Keep it factual – Personal attacks or fake reports will be removed
  • No discrimination – Reports based on race, gender, nationality, etc. will not be tolerated
  • Be professional – This is a tool to protect teams, not to shame people

🛡️ Privacy Protection

  • Do not share personal information of candidates
  • Only report behavior inappropriate in professional environments
  • Focus on facts rather than personal judgments

🎯 Ultimate Goal

Let's work together to create a safer, smarter, and more transparent hiring ecosystem for all stakeholders.
